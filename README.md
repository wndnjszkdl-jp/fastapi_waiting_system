# 스마트 대기 안내 시스템

관리자 화면에서 A·B·C방의 번호를 호출하면 대기 화면에 즉시 반영되고,
띵동 효과음과 한국어 음성으로 안내하는 FastAPI 프로젝트입니다.

## 1. PyCharm에서 실행

1. 압축을 풀고 PyCharm에서 폴더를 엽니다.
2. Python 인터프리터를 설정합니다.
3. PyCharm 터미널에서 다음 명령을 실행합니다.

```bash
pip install -r requirements.txt
```

4. 다음 명령으로 서버를 실행합니다.

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Windows에서는 `run.bat`을 실행해도 됩니다.

## 2. 접속 주소

같은 컴퓨터에서 테스트:

- 관리자 화면: http://127.0.0.1:8000/admin
- 대기 화면: http://127.0.0.1:8000/display
- API 문서: http://127.0.0.1:8000/docs

다른 기기에서 접속할 때는 서버 PC의 내부 IP를 사용합니다.

예:

- 관리자: http://192.168.0.10:8000/admin
- 대기 화면: http://192.168.0.10:8000/display

두 기기는 같은 와이파이에 연결되어 있어야 하며,
Windows 방화벽에서 Python 또는 8000번 포트의 접근 허용이 필요할 수 있습니다.

## 3. 사용 순서

1. `/admin`에서 방별로 `번호표 발급`을 누릅니다.
2. 대기자가 입장할 차례가 되면 `다음 번호 호출`을 누릅니다.
3. `/display` 화면의 번호가 실시간으로 바뀌면서 띵동 및 음성이 나옵니다.
4. 잘못 호출했으면 `한 단계 되돌리기`를 사용합니다.
5. 같은 번호를 다시 안내하려면 `재호출`을 누릅니다.

## 4. 주요 기능

- 관리자 화면과 대기 화면 완전 분리
- WebSocket 실시간 동기화
- SQLite 데이터 영구 저장
- 번호표 발급 및 방별 대기 인원 계산
- 다음 호출·재호출·되돌리기·수동 번호 설정
- 띵동 효과음
- 브라우저 한국어 TTS 안내
- WebSocket 연결 끊김 시 자동 재접속
- TV·태블릿·PC 반응형 화면
- 전체 화면 지원

## 5. 음성이 나오지 않을 때

브라우저의 자동 재생 정책 때문에 대기 화면 최초 접속 후
상단의 `소리 사용하기` 버튼을 한 번 눌러야 할 수 있습니다.
Chrome 또는 Edge 사용을 권장합니다.

## 6. 운영 팁

- 서버 PC는 행사 중 절전 모드를 꺼두세요.
- 대기 화면은 Chrome/Edge에서 전체 화면(F11)으로 실행하세요.
- 실제 행사 전 같은 와이파이에서 관리자와 대기 화면을 함께 테스트하세요.
